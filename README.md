## 🏛️ Featured project: CivicVoice

A tamper-evident public grievance platform where citizens file, track and verify civic complaints. Only a pseudonymous Citizen ID is ever public.

- Email OTP, JWT authentication and AES-256 encryption
- Google Gemini vision check that reads each photo, sets category and priority, and rejects fake proof
- Duplicate detection by text and GPS similarity, with SHA-256 hashing for tamper-evident records
- Live map, QR-code timelines, officer portal, admin dashboard, chatbot, English, Hindi and Tamil support
- Deployed on Supabase PostgreSQL, Render and Vercel

**Stack:** Next.js · Node.js · Express · Supabase PostgreSQL · Gemini API
**Code:** [github.com/monishasundaram/CivicVoice](https://github.com/monishasundaram/CivicVoice)

## 💻 Run locally

No installation needed.

```bash
git clone https://github.com/monishasundaram/Portfolio.git
cd Portfolio
```

Open `index.html` in your browser. To use a local server instead:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## 🚀 Deploy on Netlify

1. Push this repo to GitHub.
2. In Netlify, choose **Add new site → Import from Git** and select the repo.
3. Leave the build command empty and set the publish directory to `/`.
4. Every push to the main branch updates the live site.

You can also drag the project folder onto [app.netlify.com/drop](https://app.netlify.com/drop).

## 🎨 Customise

Everything lives in `index.html`:

- **Colours:** the CSS variables at the top of the `<style>` block (`--bg`, `--panel`, `--pink`).
- **Content:** the text inside the `<main>` element.
- **Typing roles:** the `roles` array in the `<script>` block.
- **Contact email:** the `mailto:` address in the form script.
